     ```python
     closed = [t for t in trades if t["exit_reason"] in _CLOSED_REASONS]   # already computed above — reuse the same list object
     if spread_price:
         for t in closed:
             risk = t["entry"] - t["sl"]
             t["pnl_points"] -= spread_price                       # net once, in instrument price units
             # Recompute r_multiple from the NETTED pnl_points so avg_r is net-of-spread.
             # r_multiple = pnl_points / abs(risk) is algebraically IDENTICAL to the existing
             # line-50 formula (exit-entry)/risk for BOTH directions, and bit-identical when
             # spread_price == 0.0 (for a short: pnl = -(exit-entry), abs(risk) = -risk, so
             # pnl/abs(risk) == (exit-entry)/risk; IEEE sign cancellation is exact). Defaults
             # therefore reproduce legacy output exactly.
             t["r_multiple"] = (t["pnl_points"] / abs(risk)) if risk else np.nan
     ```
     Do NOT use any other formula shape. `pnl_points / abs(risk)` with `risk = entry - sl` is the single
     deterministic recompute; it equals the current formula at spread_price=0.0 (golden test arbiter) and

     ```python
     # INST-01: with a spec, account-currency money = pnl_points × (tick_value/tick_size) × lot.

     money_per_point = (value_per_point * lot) if value_per_point is not None else (contract_size * lot)
     ```
