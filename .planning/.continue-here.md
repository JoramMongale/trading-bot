# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each constraint below was discovered through failure this session.

- [ ] CONSTRAINT: real money on Windows. The bots on the user's Windows PC trade real accounts. Never edit configs during a live run. Deploy only as admin cmd: `scripts\restart_bots.bat stop` → `git pull` → `scripts\restart_bots.bat start`. cmd re-reads running .bat files, so a pull that changes a .bat while supervisors run can corrupt them.
- [ ] CONSTRAINT: cmd `for /f` quoting. With more than two quotes inside `('...')`, cmd strips the outer ones and the command silently never runs. A quote fix (3bb1f08) made the supervisor abort at startup and took both bots down. Use a helper script with exactly two quotes (see `scripts/clock.py`), and test the .bat logic before pushing.
- [ ] CONSTRAINT: public repo. Never commit `config/ntfy.toml` or `config/telegram.toml` (gitignored). The ntfy topic works like a password.
- [ ] CONSTRAINT: wrong-account trap. The gold terminal was once logged in to the BTC account. `[live] expected_login` now refuses to start. Never remove it.

**Do not proceed until all boxes are checked.**
