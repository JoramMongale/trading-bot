# Requirements: Gold 5m Breakout Bot — v1.0 (shipped 2026-08-28)

**Core Value:** Detect the resistance breakout setup accurately and place correctly-priced Buy Stop orders — no missed setups, no false triggers, sensible risk.

## v1 Requirements

### Trading Strategy — VALIDATED

- [x] **STRAT-01**: Bot detects dynamic support/resistance from swing highs/lows on 5m XAUUSD (not naive min/max) — **validated** Phase 1
- [x] **STRAT-02**: Bot identifies the buy setup — bullish candle close above resistance with prior close ≤ resistance — **validated** Phase 1
- [x] **STRAT-03**: Bot computes order parameters — entry at resistance, SL below support, TP at 1:1 risk-reward — **validated** Phase 1

### Execution — VALIDATED

- [x] **EXEC-01**: Bot connects to MT5 and fetches live 5m XAUUSD bars, handling MT5-unavailable gracefully — **validated** Phase 2 (real-terminal deferred on macOS; exercised by live Windows runs)
- [x] **EXEC-02**: Bot places Buy Stop orders with SL/TP via the MT5 API — **validated** Phase 2 (real demo ticket 3110811764; live real-money orders)
- [x] **EXEC-03**: Bot settings (symbol, timeframe, lot, magic number, risk) configurable via config file — **validated** Phase 1 + 2

### Validation & Safety — VALIDATED

- [x] **SAFE-01**: Bot runs the same strategy logic over historical data and reports trade stats — **validated** Phase 1
- [x] **SAFE-02**: Bot logs every decision to a file for post-trade review — **validated** Phase 1, 2, 3
- [x] **SAFE-03**: Bot enforces demo-only trading unless live trading is explicitly enabled — **validated** Phase 2

## AI Layer (Phase 4)

- [x] **AI-01**: DeepSeek (or mock) consulted on every deterministic setup, strict JSON (bias/confidence/reasoning/invalidation) — **validated** Phase 4
- [x] **AI-02**: Pure deterministic gate validates each proposal before execution (confidence, bias agreement, stop-integrity) — **validated** Phase 4
- [x] **AI-03**: Daily market-regime assessment that can suppress setups, cadence bounded (~1/setup + 1/day) — **validated** Phase 4
- [x] **AI-04**: AI backtest replays history, gates every setup, reports raw vs AI-gated stats, every AI decision logged — **validated** Phase 4
- [x] **AI-05**: No new runtime deps, no API keys in config; env-sourced secrets, stdlib HTTP, JSONL audit — **validated** Phase 4
- [x] **AI-06**: AI layer verified in the LIVE engine behind `[ai] enabled` (wide window, `--provider` override, E2E mock + real DeepSeek) — **validated** Phase 4

## Analytics Platform (Phase 4)

- [x] **WARE-01**: Every bot artifact lands in a local DuckDB analytics database via an idempotent loader — **validated** Phase 4
- [x] **WARE-02**: A dbt project transforms raw tables into queryable marts (merged trade ledger, AI-gate activity/performance, bot health) — **validated** Phase 4

## News & Sentiment (Phase 4)

- [x] **NEWS-01**: Free keyless RSS pipeline → DuckDB with dedupe, deterministic lexicon scoring, daily sentiment snapshot — **validated** Phase 4
- [x] **NEWS-02**: Daily sentiment snapshot offered to the AI regime check as an optional, fail-open input — **validated** Phase 4

## Web Dashboard (Phase 4)

- [x] **DASH-01**: Next.js + Tailwind dashboard renders status, open position, ledger, AI-gate activity, risk, news from DuckDB marts — **validated** Phase 4 (partial truth at verification: account balance not rendered — not required by DASH-01/SC6)
- [x] **DASH-02**: Dashboard READ-ONLY and loopback-bound; no order/risk write path, no stored credentials — **validated** Phase 4
