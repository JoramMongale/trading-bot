## Overview

Milestone v1.0 delivered the full hybrid trading system described in the project's
core value: detect the resistance-breakout setup accurately and place
correctly-priced Buy Stop orders — no missed setups, no false triggers, sensible
risk. Four phases shipped: a validated strategy/backtest core, real MT5 order
placement behind a demo-safety guard, operational robustness (reconnect, weekend
guard, merged ledger), and the non-deterministic half of the hybrid (DeepSeek
advisor + deterministic gate + DuckDB/dbt warehouse + news pipeline + Next.js
dashboard). The milestone closed with both a gold (XAUUSDc) and BTC (BTCUSDc)
bot running real-money on Exness cent accounts.

## Milestone Summary

**Key Decisions:**

- Validation order backtest → demo → live; live trading is a deliberate opt-in (SAFE-03 demo-only default).
- Strategy logic in pure Python shared between backtester and live engine.
- MT5 is Windows-only → macOS development used BrokerClient ABC + SimulatedBroker + fake-MT5 tests; real-terminal verification deferred to a Windows run (02-06), later exercised live on Windows.
- TA-Lib dropped (no swing/fractal functions); pure pandas/numpy.
- S/R level expiry is window-bounded (no ffill) — fixes economically impossible stale levels.
- Risk priced at the market (ask − sl); symbol tick-value sizing from the broker (cent-account correct).
- AI: "AI proposes, deterministic code disposes"; gate fail-CLOSED, regime check fail-OPEN, news fail-open.
- Dashboard READ-ONLY by construction (read_only duckdb, GET-only routes, loopback bind).

**Issues Resolved:**

- `.ffill()` level-expiry root cause → window-bounded decay.
- Slippage double-charge (reference vs fill entry) measured and quantified; risk arithmetic moved to ask − sl.
- Data-contamination (sample CSV globbed by CLI) → DAT_ASCII-only glob + sample relocation.
- MT5 wrong-terminal and multi-terminal attach bugs → per-config terminal_path pinning.
- Concurrency: launchd start race → atomic mkdir lock; stack-lock deadlock fixed.
- Market-entry order path verified end-to-end on demo + real-money accounts.

**Issues Deferred (to next milestone / backlog):**

- 02-06 real-MT5 verification closed deferred (later exercised by live Windows runs).
- 03-HUMAN-UAT optional item: real-DeepSeek dry-run re-confirmation (pending).
- Unauthenticated MT5 RPC bridge on :8001 — needs SSH tunnel / bind 127.0.0.1 + credential rotation after the 2026-08-19 malware incident.
- Live strategy edge is at/under the noise bar (best |t| = 2.46 vs noise-beats-it-42% calibration); BTC is a machinery test.
- Dashboard `/api/*` routes orphaned; overview reads raw tables (DASH-01 wording exceeded); no automated tests for dbt marts or the Next.js app.
- `trade_ledger.py` globs `live_*.log` but CLI default is `live.log`; raw_ledger has no mart consumer.
