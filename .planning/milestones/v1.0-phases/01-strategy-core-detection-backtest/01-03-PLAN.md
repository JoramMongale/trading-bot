    `src/trading_bot/backtest/engine.py` — `run_backtest(df, fractal_left=2, fractal_right=2,
    sr_lookback=60, sl_buffer=0.01) -> list[dict]`:
    - Pass A: `df = df.copy()`; chain `support_resistance(detect_swings(df, left, right), sr_lookback)`;
      then `detect_setups(df)`.
    - Pass B event loop per RESEARCH.md: (1) manage open trade first — SL before TP within a bar
      (pessimistic); (2) fill pending Buy Stop from bar t+1 onward when `high >= entry`,
      fill price `max(entry, open)` (gap-open fills at open); a bar that fills may not also arm a new
      setup; (3) new setup → arm `entry=resistance`, `sl=support - sl_buffer`, `tp=entry + (entry - sl)`
      (exact 1:1). Appends a trade record EXACTLY ONCE, at exit.
    - End of data: open trade → `exit_reason="OPEN"`, `exit_price=last close` (still appended).
    - Trade record fields: `entry_time, entry, sl, tp, exit_time, exit_price, exit_reason`.
    - Signal on the final bar arms a pending order that never fills → NO trade record.

    `src/trading_bot/backtest/stats.py` — `trade_stats(trades, contract_size=100.0, lot=0.01) -> dict`:
    - closed = trades with `exit_reason in ("SL", "TP")`; enrich each trade with `pnl_points`
      (`exit_price - entry`) and `r_multiple` (`pnl_points / (entry - sl)`, NaN if risk == 0).
    - Return: `total_trades` (closed count), `open_trades`, `wins`, `losses`, `win_rate`,
      `net_pnl_points`, `net_pnl_usd` (points × contract_size × lot), `avg_r`, `profit_factor`
      (gross_win / gross_loss; `inf` when gross_loss == 0), `max_drawdown_usd`
      (from closed-trade equity curve `pnl.cumsum() * contract * lot` via `cummax - cumsum`),
      `avg_trade_bars` (mean `exit_time - entry_time` in bar count — compute via index positions;
      guard empty list → 0.0). Empty trades list → all zeros (`profit_factor` 0.0, not inf).

    `tests/test_backtest.py` MUST cover, each with hand-computed expected values:
    1. Fill timing: setup at bar t → NO trade entered at t; filled at t+1 when `high >= entry`.
    2. Gap-open fill: bar t+1 opens ABOVE entry → fill price == open of t+1 (not entry).
    3. Exact 1:1 R:R: assert `tp == entry + (entry - sl)` for every record.
    4. Pessimistic ordering: one bar with `low <= sl` AND `high >= tp` → `exit_reason == "SL"`.
    5. One trade at a time: second setup while a trade is open → only 1 trade in output.
    6. Signal on final bar → 0 trades (no lookahead fill).
    7. OPEN exit: trade still open at last bar → `exit_reason == "OPEN"`, `exit_price == last close`,
       counted in `open_trades`, excluded from wins/losses but included in net P&L.
    8. Stats math: known trades → assert `net_pnl_points`, `net_pnl_usd` (×100×0.01),
       `win_rate`, `profit_factor`, `max_drawdown_usd` exactly.
    9. Golden integration: one small M5 frame (≤ 15 bars) producing ≥ 2 trades with known-by-hand
       records — assert the FULL record list (entry/exit times, prices, reasons).
    Run `.venv/bin/pytest tests/test_backtest.py -q -W error::FutureWarning`.
