  <behavior>
    All functions operate on a DataFrame with columns `open, high, low, close` (plus optional extra columns,
    which must be preserved). Defaults: `left=2, right=2, lookback=60`.

    `detect_swings(df, left=2, right=2) -> df` adds columns:
    - `swing_high_raw` / `swing_low_raw`: swing high at i iff `high[i] >= max(high[i-left..i-1])`
      AND `high[i] > max(high[i+1..i+right])`; swing low symmetric with `<=` and `<`.
      `>=`/`<=` on the LEFT makes the LAST bar of an equal-high/low plateau the swing point;
      strict `>`/`<` on the RIGHT keeps confirmation honest.
    - `swing_high` / `swing_low`: `raw.shift(right)` — confirmed, no-lookahead columns.
    Test cases (input -> expected):
    - Rising peak: highs `[1,2,3,4,3,2,1]` (left=right=2) -> swing_high_raw at index 3 = 4;
      `swing_high` is NaN at index 3 and 4, equals 4 at index 5 (shift by right proves no lookahead);
      `swing_high` NaN at indices 0-2 and 6.
    - Plateau: highs `[1,2,2,1,0.5]` -> the LAST bar of the equal-high plateau (index 2) is the swing
      (2 >= left max of `[1,2]`, and 2 > right max of `[1,0.5]`); index 1 is NOT a swing.
    - Symmetric low test: lows `[5,4,3,4,5]` -> swing_low_raw at index 2 = 3; confirmed at index 4.
    - Frame start: first `left` bars cannot be swings (rolling min_periods) -> NaN there.
    - Purity test: read the three source files' text and assert none of them import anything other than
      `pandas`/`numpy` (e.g. regex `^import |^from ` lines against an allowlist; or an ast-based check).

    `support_resistance(df, lookback=60) -> df` adds columns:
    - `resistance = swing_high.rolling(lookback, min_periods=1).max().ffill()`
    - `support = swing_low.rolling(lookback, min_periods=1).min().ffill()`
    Test cases:
    - NaN until the first CONFIRMED swing of that type exists (resistance stays NaN while `swing_high`
      is all NaN, even though raw highs exist — proves no lookahead into unconfirmed swings).
    - After a confirmed swing, the level persists via ffill across following bars (level from bar i
      is still the level at bar i+5 when no newer swing appears).
    - A newer higher swing raises resistance; a newer lower swing lowers it.
    - Lookback window: an old swing older than `lookback` bars stops contributing (resistance falls
      to the next-most-recent swing or NaN).

    `detect_setups(df) -> df` adds a boolean column:
    - `setup = (close > resistance) & (close.shift(1) <= resistance.shift(1))` (STRAT-02).
    Test cases:
    - Fires: close `[10,10,9,9.5,10.5]`, resistance `[NaN,NaN,10,10,10]` -> `setup` True ONLY at index 4.
    - Re-trigger disabled: close `[10,10,9,11,11.5]`, resistance `[10,10,10,10,10]` -> `setup` True at
      index 3, False at index 4 (prior close 11 > resistance, so no re-fire after breakout).
    - NaN levels never produce a setup (resistance NaN -> comparison False).
    - DataFrame with extra columns (e.g. `volume`) passes through unchanged.
  </behavior>
