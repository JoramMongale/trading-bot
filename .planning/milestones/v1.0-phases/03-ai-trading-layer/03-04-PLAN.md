<objective>
News/sentiment pipeline (upgrade.txt Phase 2: "Gather historical price action,
financial news, and sentiment data sources"): a free, keyless, offline-first
feed of gold-news headlines into DuckDB, a deterministic sentiment score, and
a daily snapshot handed to the AI regime check.

Purpose: The DeepSeek regime reader currently judges "trending/ranging/choppy"
from bars alone. News sentiment is the missing macro input the upgrade.txt
plan calls for — and it must be free (no paid news API), deterministic
(lexicon scoring, not another model call), and fail-open (no news must never
stop the day). The pipeline writes into the DuckDB warehouse from 03-03 and
feeds the AI layer from 03-01/03-02 without adding any runtime dependency to
the bot's trading path.
Output: [news] config, RSS fetcher, lexicon scorer, dbt news marts, a
sentiment snapshot, and AI regime-context integration.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public RSS feeds -> parser | Remote untrusted XML crosses into ElementTree |
| parser -> DuckDB | Parsed articles cross into raw_news_articles |
| snapshot file -> AIEngine | Local JSON crosses into the DeepSeek prompt |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04-01 | T (XXE / external entity in RSS XML) | news/fetch.py ElementTree | mitigate | xml.etree.ElementTree does not resolve external entities by default; additionally reject responses > 2 MB and non-200 statuses before parsing. Never fetch URLs found inside the feed. |
| T-04-04-02 | I (hostile feed content -> prompt) | snapshot -> regime prompt | mitigate | Only title/description strings reach the snapshot; the DeepSeek regime prompt instructs JSON-only output and the regime result is parsed strictly (AIResponseError on unparseable -> fail OPEN). Sentiment is a float score + short headlines, not free text. |
| T-04-04-03 | E (news outage blocks trading) | AIEngine._maybe_regime_check | mitigate | Fail-open by design: snapshot absent/corrupt/unreadable -> sentiment=None, day continues (logged ai_regime_sentiment_unreadable). The regime check's own failure policy is unchanged (fail OPEN). |
| T-04-04-04 | I (snapshot file tampering) | write_snapshot | accept | Local file in gitignored output/ written by the user's own script; worst case a stale/wrong score reaches a prompt the gate still validates. Low-value target, no credentials involved. |
| T-04-04-05 | D (dedupe key collision) | fetch.py link dedupe | mitigate | Natural key = normalized link (lowercase, trailing-slash stripped); MERGE upsert keeps the newest fetched_at so re-fetches update rather than duplicate. |
</threat_model>
