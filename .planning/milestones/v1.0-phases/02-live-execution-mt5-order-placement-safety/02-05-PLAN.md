  <files>src/trading_bot/cli.py, tests/test_cli.py</files>
  <action>
    Extend `src/trading_bot/cli.py` (which currently has only `backtest`) with a `live` subcommand. Preserve the existing `backtest` path and exit-code conventions (0 success, 1 config/data errors, 2 bad arguments).

    1. **Broker factory** (module-level function `build_broker(cfg) -> BrokerClient`, placed in cli.py — do NOT create a new module):
       - `if cfg.live.mode == "dry-run":` → `DryRunBroker(SimulatedBroker(trade_mode=0), logger=None)` (a fresh in-memory broker; no data → polls will log `bar_fetch_failed` until real data exists — acceptable and documented for dry-run on macOS; the E2E test in Task 2 seeds it).
       - `else:` → `MT5Broker(symbol=cfg.data.symbol)` (demo or live mode; the engine's safety gate + connect() failures handle the rest).
    2. **`parse_args`**: add subparser:
       ```
       live = sub.add_parser("live", help="run the live bot (dry-run/demo/live)")
       live.add_argument("--config", default="config/config.toml", ...)
       live.add_argument("--once", action="store_true", help="run one poll and exit")
       live.add_argument("--mode", choices=["dry-run", "demo", "live"], default=None,
                         help="override [live] mode from config")
       ```
    3. **`main(argv)`: handle `args.command == "live"`**:
       - Load config (same try/except as backtest → exit 1 on FileNotFoundError/ValueError with `error: ...` on stderr).
       - Apply `--mode` override onto `cfg.live` if given (rebuild the frozen config via `dataclasses.replace(cfg, live=dataclasses.replace(cfg.live, mode=args.mode))`).
       - Create `logger = get_logger("live", str(output_dir / "live.log"))` where `output_dir = Path(cfg.backtest.output_dir)`; mkdir parents.
       - `log_decision(logger, "live_start", mode=cfg.live.mode, symbol=cfg.data.symbol, timeframe=cfg.data.timeframe, magic=cfg.live.magic_number, lot=cfg.trading.lot, enabled=cfg.live.enabled)`.
       - `broker = build_broker(cfg)`; `engine = LiveEngine(cfg, broker, logger)`.
       - If mode != "dry-run": `broker.connect()` wrapped in try/except `BrokerUnavailableError` → print `error: <msg>` to stderr, `log_decision(logger, "live_stop", reason="connect_failed")`, return 1.
       - Loop:
         - `if args.once:` → `result = engine.poll_once()`; print a one-line summary of `result`; break.
         - `else:` → loop `while True:` `engine.poll_once()`; `time.sleep(cfg.live.poll_interval)`; catch `KeyboardInterrupt` → `log_decision(logger, "live_stop", reason="keyboard_interrupt")`, print `stopped`, return 0.
       - Any uncaught `BrokerUnavailableError`/`BrokerRejectedError` inside the loop → print `error: ...` to stderr, log `live_stop`, return 1 (graceful EXEC-01).
    4. **Tests (`tests/test_cli.py` — extend existing file)**:
       - `test_cli_live_bad_mode_rejected`: `main(["live", "--mode", "paper"])` → returns 2 (argparse rejects the choice).
       - `test_cli_live_dry_run_once_no_config_crash`: run `main(["live", "--once", "--config", <tmp config with [live] table>])` → returns 0 (dry-run with an empty SimulatedBroker logs `bar_fetch_failed` but does not crash), and `output/live.log` exists containing `event=live_start`.
       - `test_cli_live_missing_config`: `main(["live", "--config", "/nonexistent"])` → 1 with `error:` on stderr.
