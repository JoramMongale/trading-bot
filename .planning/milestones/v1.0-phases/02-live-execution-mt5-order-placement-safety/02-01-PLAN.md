    Create the `src/trading_bot/broker/` package. `broker/__init__.py` may be empty or re-export the public names from base.py. No MT5 imports anywhere in this plan — `MetaTrader5` is Windows-only and must stay out of these files (RESEARCH.md).

    **`broker/base.py`** — typed broker contract (dataclasses + ABC + errors). Use stdlib only (`abc`, `dataclasses`, `pandas` for the rates DataFrame type in type hints only where needed — actually keep type hints as strings to avoid hard pandas coupling; pandas is already a dependency so importing it for `DataFrame` annotations is fine).
    - `@dataclass(frozen=True) class AccountInfo`: `login: int`, `server: str`, `currency: str`, `balance: float`, `trade_mode: int` (0=demo, 1=contest, 2=real — mirror MT5's `ACCOUNT_TRADE_MODE_*` values).
    - `@dataclass(frozen=True) class OrderRequest`: `symbol: str`, `volume: float`, `entry: float` (Buy Stop price = resistance), `sl: float`, `tp: float`, `magic: int`, `deviation: int`, `comment: str`. Add a `to_log_fields()` method returning `dict[str, object]` for SAFE-02 logging (keys: symbol, volume, entry, sl, tp, magic).
    - `@dataclass(frozen=True) class OrderResult`: `ticket: int`, `placed: bool`, `retcode: int`, `comment: str`.
    - `@dataclass(frozen=True) class PendingOrder`: `ticket: int`, `symbol: str`, `entry: float`, `sl: float`, `tp: float`, `magic: int`. Add `equivalent_to(other: OrderRequest) -> bool` returning True when symbol matches, magic matches, and `abs(entry - other.entry) <= 0.01` (XAUUSD 2-dp tolerance) — used for re-trigger dedup (phase success criterion 5).
    - `@dataclass(frozen=True) class Position`: `ticket: int`, `symbol: str`, `magic: int`.
    - `class BrokerError(Exception)`, `class BrokerUnavailableError(BrokerError)` (MT5 package/terminal not available), `class BrokerRejectedError(BrokerError)` (order_send returned a failure retcode).
    - `class BrokerClient(ABC)` with abstract methods:
      - `connect() -> None` (raise BrokerUnavailableError if the broker cannot be used)
      - `disconnect() -> None`
      - `fetch_rates(symbol: str, timeframe: str, count: int) -> pd.DataFrame` — returns CLOSED bars only, OHLC columns `["open","high","low","close"]`, datetime index named `"time"` (the exact shape `strategy.swings/levels/signals` expect)
      - `account_info() -> AccountInfo`
      - `place_buy_stop(request: OrderRequest) -> OrderResult`
      - `pending_orders(symbol: str, magic: int) -> list[PendingOrder]`
      - `positions(symbol: str, magic: int) -> list[Position]`

    **`broker/simulated.py`** — `SimulatedBroker(BrokerClient)` for tests, dry-run, and the E2E replay. Constructor: `SimulatedBroker(rates: pd.DataFrame | None = None, trade_mode: int = 0)`.
    - `rates`: a full M5 OHLC DataFrame (datetime index named "time"). Internal `_cursor` int starts at `len(rates)`. `fetch_rates(symbol, timeframe, count)` returns the last `count` rows ending at `_cursor` (so `_cursor` acts as "now" — the forming bar is simulated as excluded). If rates is None → raise `BrokerUnavailableError` (mirrors a terminal with no data).
    - `advance() -> None` — move `_cursor` forward by one bar (used by the E2E replay to simulate new closed bars arriving).
    - `account_info()` returns `AccountInfo(login=123456, server="Simulated", currency="USD", balance=10000.0, trade_mode=self._trade_mode)`.
    - `place_buy_stop(request)` appends an `OrderResult(ticket=len(ledger)+1000, placed=True, retcode=10009, comment="simulated")` to an internal `_orders: list[dict]` ledger (store the OrderRequest fields + ticket + `pending=True`) and returns it. Never fails.
    - `pending_orders(symbol, magic)` returns `PendingOrder` objects from the ledger where `pending` is True, symbol matches, and magic matches.
    - `positions(symbol, magic)` returns from an internal `_positions` list (default empty; tests can set it directly).
    - Add a test helper `simulate_fill(ticket: int) -> None` that marks a ledger order `pending=False` (so dedup tests can expire an order), and `simulate_position(...)` to seed `_positions`.
    - `connect()/disconnect()` are no-ops (always "connected").

    **Tests (`tests/test_broker_simulated.py`)**:
    - fetch_rates returns the requested window ending at the cursor, closed-bar shape (columns open/high/low/close, index named "time"), and the window shifts as `advance()` is called
    - fetch_rates on a broker with no rates raises BrokerUnavailableError
    - place_buy_stop appends to the ledger, returns ticket > 0, placed=True, retcode 10009
    - pending_orders filters by symbol + magic and returns only pending entries; after `simulate_fill(ticket)`, that order no longer appears
    - `PendingOrder.equivalent_to` matches on symbol+magic+entry within 0.01 and rejects differing entries/magics
    - `OrderRequest.to_log_fields()` contains symbol/volume/entry/sl/tp/magic
