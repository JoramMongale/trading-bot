<objective>
Live engine — poll bars, detect setups, place Buy Stop orders with dedup and safety.

Purpose: The phase's core loop (phase success criteria 1, 2, 5 + SAFE-01/SAFE-02). On each poll the engine fetches only CLOSED bars from the broker (never the forming bar), runs the SAME pure strategy chain the backtester uses, and when the last closed bar shows a setup it builds the order with the SAME arithmetic as `backtest/engine.py` (entry=resistance, sl=support−sl_buffer, tp=entry+(entry−sl)), then dedup-checks, safety-checks, and places via the broker. Fully testable on macOS against SimulatedBroker.

Output:
- `live/engine.py` — `LiveEngine`
- `tests/test_live_engine.py` — golden-frame behavioral tests
</objective>

  <files>src/trading_bot/live/engine.py, tests/test_live_engine.py</files>
  <action>
    Create `src/trading_bot/live/engine.py` with the detection half of the engine. Order placement lands in Task 2 of this same plan.

    **`class LiveEngine`**:
    - Constructor: `LiveEngine(cfg, broker, logger)` where `cfg` is a `Config`, `broker` is a `BrokerClient` (from plan 02-01), `logger` is a `logging.Logger` (from `logging_utils.get_logger`).
    - Store: `_cfg`, `_broker`, `_logger`, `_last_bar_time: pd.Timestamp | None = None` (dedup across polls — a setup must not re-fire on a bar already processed).
    - `_n_bars()` helper: `count = cfg.strategy.sr_lookback + cfg.strategy.fractal_left + cfg.strategy.fractal_right + 5` (enough history for confirmed swings + S/R window).
    - `poll_once() -> dict` — ONE iteration, returns an event dict describing what happened. Steps:
      1. `df = self._broker.fetch_rates(cfg.data.symbol, cfg.data.timeframe, self._n_bars())` — wrap in try/except `BrokerUnavailableError` → `log_decision(self._logger, "bar_fetch_failed", reason=str(exc))` and return `{"event": "bar_fetch_failed", "error": str(exc)}`. (Graceful when MT5 unavailable — EXEC-01.)
      2. If `df.empty` → `log_decision("bar_check", new_bar=False, reason="no_data")`; return `{"event": "bar_check", "new_bar": False}`.
      3. `new_bar_time = df.index[-1]`. If `self._last_bar_time is not None and new_bar_time <= self._last_bar_time` → no new bar; return `{"event": "bar_check", "new_bar": False}` (do NOT re-evaluate the same closed bar).
      4. Set `self._last_bar_time = new_bar_time`.
      5. Run the strategy chain (copy-paste the pipeline from `backtest/engine.py` Pass A):
         ```python
         df = strategy.support_resistance(
             strategy.detect_swings(df, cfg.strategy.fractal_left, cfg.strategy.fractal_right),
             cfg.strategy.sr_lookback,
         )
         df = strategy.detect_setups(df)
         ```
         (`strategy` = `trading_bot.strategy` package; import the three functions directly to mirror engine.py.)
      6. `setup = bool(df["setup"].iloc[-1])` on the LAST CLOSED bar.
      7. If not setup: `log_decision(self._logger, "bar_check", new_bar=True, setup=False, bar=new_bar_time)`; return `{"event": "bar_check", "new_bar": True, "setup": False, "bar": new_bar_time}`.
      8. If setup: `log_decision(self._logger, "setup_detected", bar=new_bar_time, entry=float(df["resistance"].iloc[-1]), sl=float(df["support"].iloc[-1] - cfg.strategy.sl_buffer), tp=...)` (compute tp = entry + (entry − sl), same as backtest). Return `{"event": "setup_detected", "bar": new_bar_time, "entry": ..., "sl": ..., "tp": ...}`.
    - Round decision-log floats to 2 decimals at the log boundary (XAUUSD 2-dp), matching the CLI's existing rounding convention.
    - The engine must import ONLY `pandas`, `trading_bot.strategy.*`, `trading_bot.broker.base`, `trading_bot.live.safety`, `trading_bot.logging_utils` — never `MetaTrader5`.

    **Tests (`tests/test_live_engine.py`)** — reuse the golden 12-bar OHLC fixture values from `tests/test_cli.py` (`_FIX_*` lists, which are the SAME frame that produces a known setup in `test_backtest.py`). Build a `SimulatedBroker(rates=golden_df)`:

    - `test_bar_fetch_failed_graceful`: broker with no rates (`SimulatedBroker(rates=None)`... adapt so `fetch_rates` raises `BrokerUnavailableError`) → `poll_once()` returns `bar_fetch_failed` and does not crash.
    - `test_bar_check_logs_no_setup`: a flat/quiet frame → `bar_check` with setup=False.

  <files>src/trading_bot/live/engine.py, tests/test_live_engine.py</files>
  <action>
    Extend `LiveEngine` with the order-placement half. Add a method `on_setup(entry, sl, tp, bar_time) -> dict` that `poll_once()` calls when `setup_detected`:

    1. **Dedup — equivalent pending order** (phase success criterion 5):
       - `pending = self._broker.pending_orders(cfg.data.symbol, cfg.live.magic_number)`
       - `req = OrderRequest(symbol=cfg.data.symbol, volume=cfg.trading.lot, entry=entry, sl=sl, tp=tp, magic=cfg.live.magic_number, deviation=cfg.live.deviation, comment=cfg.live.comment)` (from `broker.base`).
       - If any `p.equivalent_to(req)` → `log_decision("order_skipped", reason="pending_order_equivalent", bar=bar_time, entry=entry)`; return `{"event": "order_skipped", "reason": "pending_order_equivalent"}`.
    2. **Dedup — open position** (backtest one-at-a-time parity):
       - `pos = self._broker.positions(cfg.data.symbol, cfg.live.magic_number)`; if any → `log_decision("order_skipped", reason="position_open", ...)`; return skip event.
    3. **Safety gate** (SAFE-03, plan 02-03):
       - `from trading_bot.live.safety import verify_execution_allowed, SafetyError`
       - `try: verify_execution_allowed(self._cfg, self._broker.account_info())`; `except SafetyError as exc:` → `log_decision("order_skipped", reason="safety_blocked", detail=str(exc), bar=bar_time)`; return `{"event": "order_skipped", "reason": "safety_blocked", "detail": str(exc)}`.
    4. **Place**:
       - `result = self._broker.place_buy_stop(req)` — wrap in `BrokerRejectedError` catch → `log_decision("order_rejected", bar=bar_time, reason=str(exc), **req.to_log_fields())`; return `{"event": "order_rejected", "error": str(exc)}`.
       - On success: `log_decision("order_placed", bar=bar_time, ticket=result.ticket, **req.to_log_fields())`; return `{"event": "order_placed", "ticket": result.ticket, "entry": entry, "sl": sl, "tp": tp}`.
    - `poll_once()` step 8 becomes: compute entry/sl/tp, log `setup_detected`, then `return self.on_setup(entry, sl, tp, new_bar_time)`.
    - All prices rounded to 2 dp in logs; OrderRequest carries full precision.

    **Tests (extend `tests/test_live_engine.py`)**:
    - `test_places_order_on_setup`: SimulatedBroker with golden frame; walk to setup → assert `order_placed` event, ledger length 1, ticket > 0, and the placed request has entry/sl/tp == the detected values and magic == cfg.live.magic_number.
    - `test_skips_equivalent_pending`: place once, `advance()` past the setup bar, and engineer a second setup-bearing frame with the same entry (e.g., append bars so the strategy re-arms at the same resistance — if hard to construct, directly seed `broker._orders` with an equivalent pending order via `simulate` helper from plan 02-01, then call `poll_once()` on a setup bar) → assert `order_skipped reason=pending_order_equivalent` and ledger length stays 1.
    - `test_skips_when_position_open`: seed `broker._positions` with a position for symbol+magic → assert `order_skipped reason=position_open`.
    - `test_safety_block_real_account`: `SimulatedBroker(..., trade_mode=2)` with cfg.live.enabled=False → assert `order_skipped reason=safety_blocked` and NO order in ledger. Then flip cfg.live.enabled=True → order placed.
    - `test_dry_run_never_places`: wrap SimulatedBroker in `DryRunBroker` (from plan 02-02) → setup bar → `order_placed`-equivalent event with ticket=0/placed=False and the inner SimulatedBroker ledger stays empty.

    - Assert every event dict is JSON-serializable (no Timestamp/float artifacts beyond plain types — convert `bar` to ISO string in returned dicts and logs).
