  <how-to-verify>
    On a Windows machine with MT5 running and logged into a DEMO account:

    1. Copy the project to the Windows machine, create a venv, `pip install -e ".[dev]"` and `pip install MetaTrader5`.
    2. Run `.venv\Scripts\python -m trading_bot.cli live --once --mode dry-run` — confirm it exits 0, writes `output/live.log` with `event=live_start` and `event=bar_fetch_failed` or `bar_check` (no crash).
    3. Run `.venv\Scripts\python -m trading_bot.cli live --mode demo` (config `[live] mode = "demo"`, `enabled = false`) for 1-2 minutes — confirm:
       - `event=live_start`, repeated `event=bar_check new_bar=True setup=False/True` lines with real XAUUSD prices
       - if a setup appears, `event=order_placed` with a real ticket, OR `event=order_skipped` with a reason
       - the pending order appears in the MT5 terminal's "Trading" tab with correct entry/SL/TP (1:1 R:R, entry=resistance)
    4. Safety-guard check: with `[live] mode="live"` and `enabled=false`, connect to a REAL (non-demo) account — confirm the bot refuses with `order_skipped reason=safety_blocked` (or refuses to place) and NO order reaches the terminal. Then set `enabled=true` and confirm it allows (only if the user explicitly consents to live-account testing).
    5. Dedup check: while a Buy Stop is already pending at the same entry, confirm a subsequent identical setup produces `order_skipped reason=pending_order_equivalent` and no duplicate order.
