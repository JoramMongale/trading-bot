  <action>
    Create the `live/` package and the SAFE-03 guard.

    **`live/__init__.py`**: package docstring only.

    **`live/safety.py`**:
    - `class SafetyError(Exception)` — raised when the guard blocks execution.
    - `ACCOUNT_TRADE_MODE_DEMO = 0`, `ACCOUNT_TRADE_MODE_REAL = 2` module constants (mirror MT5 values; used so `safety.py` never imports MetaTrader5).
    - `def verify_execution_allowed(cfg, account) -> None`:
      - `cfg` is a `Config` from `trading_bot.config` (has `.live`); `account` is an `AccountInfo` from `trading_bot.broker.base` (has `.trade_mode`).
      - Rule 1 (dry-run): if `cfg.live.mode == "dry-run"` → return immediately (orders are never sent; this is enforced by the DryRunBroker seam from plan 02, and the guard's early return documents it).
      - Rule 2 (real-account opt-in): if `account.trade_mode == ACCOUNT_TRADE_MODE_REAL` and not `cfg.live.enabled` → raise `SafetyError("REFUSED: REAL trading account detected (trade_mode=2) but live.enabled=false. Demo-only enforcement (SAFE-03). Set [live] enabled=true only to explicitly opt in.")`.
      - Rule 3 (demo mode + real account): if `cfg.live.mode == "demo"` and `account.trade_mode == ACCOUNT_TRADE_MODE_REAL` → raise `SafetyError("REFUSED: mode='demo' but account is REAL. Switch to a demo account or explicitly set [live] enabled=true.")`.
      - Otherwise (demo account, or live mode + explicitly enabled) → return.
      - Order the checks dry-run first, then the two real-account rules.
    - Keep it a pure function: no logging, no broker access, no MetaTrader5 import. The ENGINE decides what to do with the exception (log + skip); the guard only decides yes/no.

    **Tests (`tests/test_safety.py`)**:
    - Build small helper configs via `load_config` with a tmp TOML (reuse the pattern from `tests/test_cli.py::_write_tmp_config`, adding a `[live]` table) or construct `Config` directly via the dataclasses; the direct-construction approach is fine and faster.
    - Parametrize:
      - mode=dry-run + trade_mode=REAL → no raise (dry-run never sends)
      - mode=dry-run + trade_mode=DEMO → no raise
      - mode=demo + trade_mode=DEMO → no raise
      - mode=demo + trade_mode=REAL → SafetyError (and message contains "REAL")
      - mode=live + enabled=false + trade_mode=REAL → SafetyError (message mentions live.enabled)
      - mode=live + enabled=true + trade_mode=REAL → no raise (explicit opt-in)
      - mode=live + enabled=false + trade_mode=DEMO → no raise (demo accounts are always fine)
      - mode=live + enabled=true + trade_mode=DEMO → no raise
    - Assert `safety.py` does not import `MetaTrader5` (grep source or inspect via a test reading the file text).
    Run the suite; see <verify>.
